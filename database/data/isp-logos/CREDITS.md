# Logos des fournisseurs d'accès

Logos des opérateurs livrés avec TechIndex, issus de Wikimedia Commons.
Ils sont dans le domaine public en tant que logos textuels ou simples
(modèle Commons « PD-textlogo ») mais restent des **marques déposées** de
leurs titulaires : ils ne servent qu'à identifier l'opérateur dans la
documentation interne, sans suggérer de partenariat.

Les fichiers PNG et JPEG sont les vignettes de 250 pixels de large produites
par Wikimedia à partir du fichier d'origine. Un administrateur peut
remplacer chaque logo depuis Administration › Fournisseurs d'accès.
